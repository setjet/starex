# Code of conduct

Starex is a small, friendly project. Everyone who takes part — in issues, pull requests or
anywhere else — agrees to:

- be respectful and patient, and assume good intent;
- keep criticism about code and ideas, never about people;
- welcome newcomers and questions;
- not harass, insult or exclude anyone.

Maintainers may edit or remove content and block people who do not follow this. Report a
problem privately to the maintainers through a
[GitHub security advisory](https://github.com/setjet/starex/security/advisories/new) or by
contacting a maintainer directly.

This code adapts the spirit of the [Contributor Covenant](https://www.contributor-covenant.org).
